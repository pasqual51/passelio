    Visual identity
    Make this workspace your own.
    Logo and favicon
    Validated images
    PNG, JPEG or WebP only, up to 5 MiB and 20 megapixels. Images are resized, metadata is stripped and files are re-encoded as PNG. SVG, video and animated images are not accepted.
    Visual assets have a separate budget: 12 files and 32 MiB total. They use the same physical data volume as the application.
    

    Background images
    Choose up to eight images
    Selected backgrounds are shown with a light overlay for readability. Rotation is disabled when reduced motion is requested. Images are stored on your server; no external image service is contacted.
    

    Theme
    Data-only themes
    Themes contain three colors, not CSS or executable code. Contrast is checked before saving. Imported themes fill the editor; they are only activated when you click Apply theme.
    

    System settings

    General
    Application name
    Shown in the header, browser title and footer. No HTML is interpreted.
    Application URL
    Used in share and email links. It does not create DNS records or configure HTTPS. Check that your domain reaches this instance before changing it.
    Login message
    A welcome message or announcement shown before sign-in.
    Default language
    Fallback language when there is no saved preference and the browser language is not supported.
    

    Sharing
    Storage
    These limits apply immediately. They do not resize your disk. Existing files are not deleted.
    Expiry (days)
    Defaults apply to new shares. The maximum is enforced by the server. Existing shares are not extended or deleted.
    Require a share password
    New shares must have at least 8 password characters. The password is never included in emails.
    Storage quota
    Limits do not resize your disk. Existing files are not deleted.
    

    Notifications
    Automatic CC
    CC is visible to recipients. BCC is hidden from message headers. Both receive the share link. Inform your users about these copies.
    SMTP test
    Test emails never use automatic copies. Configure SMTP before saving notification settings.
    

    

    Authentication
    Session lifetime
    Applies to new sessions. A reduction also shortens existing sessions; an increase does not extend them.
    Account security
    Accounts are created by administrators, passwords require 14 characters, and login is rate-limited. Public registration, SSO and MFA are not available in this alpha.
    

    Full backups
    Archives include files, account data and installation secrets. Keep them private and store an encrypted copy outside this server. Restore is performed offline into a new directory.
    Older archives are removed only after a new verified backup succeeds. Keep enough disk space for existing backups plus one new full archive.
    Database backup
    Downloads a consistent SQLite snapshot. This contains account hashes, share links and mail metadata: keep it private. Uploaded files and the separate SMTP password file are not included. For a complete restore, back up the entire data volume while services are stopped.
    Exports are limited to databases up to 32 MiB. Larger instances require a volume backup. Restore through the interface is not available.
